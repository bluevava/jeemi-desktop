# Bundled offline routing data

These text lists are a fixed snapshot from [MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat/tree/1fc5de325d54d3b77d6b86a1db900c5e48ae1003), revision `1fc5de325d54d3b77d6b86a1db900c5e48ae1003`, retrieved on 2026-11-06 and extended from the same revision on 2026-11-11. See `sources.json` for the upstream path, size and SHA-256 of each unchanged list. Upstream copyright and GPL-3.0 terms are retained in `LICENSE.txt`.

Jeemi groups these lists into editable local Jeemi (GitHub/Apple), AI+Google, IM (Telegram/Discord/WhatsApp/LINE), and Video (Netflix/Spotify/X-com/Instagram/YouTube) rules. Netflix domain and IPv4/IPv6 entries share one classical rule set, with no-resolve on IP entries, so Video emits exactly five application rules. Instagram is independent. Google payload generation excludes YouTube-specific entries from the upstream superset; the stored snapshots remain unchanged. IM/Video take precedence over broader Google API domains. Names and Emoji are Jeemi metadata. The client bundles these files and does not fetch updates from the repository. User edits remain local and are not replaced by creating another preset.

The general preset uses inline `GEOSITE,CN` and `GEOIP,CN` rules referencing databases managed by Jeemi's GEO feature, rather than a bundled CN domain/IP snapshot. Database installation/import remains separate. The process preset has no CN GEO rules.

`process-direct-windows.yaml`, `process-direct-darwin.yaml`, and `process-direct-linux.yaml` are Jeemi-authored, editable process expressions, based on the application categories in the user-provided Jeeyio Windows routing reference. Each contains only its platform’s directory boundaries, exact process names or app bundles, including Edge on Windows, Chrome on macOS and Firefox on Linux as ordinary payload entries. macOS matches Chrome's main process and the complete literal Google Chrome.app directory; Safari and shared WebKit processes have no direct-routing entry. Creating a process preset saves and binds only the current platform's process group and rule set. macOS entries are organized into ten editable application categories. Imported or existing foreign-platform rules remain saved but are skipped during composition, without changing the system default browser. The two system update domain exceptions and the general-versus-process ordering follow the reference configurations. No private subscription URL, node or credential is stored here. These local defaults are covered by the project's GPL-3.0 license.
